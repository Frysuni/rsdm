# Lock {#lock}

Lock — клиент Wayland, использующий ext-session-lock-v1. Он работает с RSDM DM или без него.

## Включение и проверка {#enable-and-try}

::: code-group

```toml [TOML]
[lock]
enable = true
```

```nix [NixOS]
services.rsdm.lock.enable = true;
```

:::

Внутри графического сеанса от имени обычного пользователя:

```sh
rsdm lock
```

Введите пароль учётной записи для разблокировки. Пустое поле может начать диалог PAM (например, аутентификацию по отпечатку пальца или токену). Последующие запросы запрашивают собственные учётные данные. Композитор должен поддерживать и разрешать протокол session-lock; см. [совместимость](compatibility.md).

## Сочетания клавиш {#keyboard-shortcuts}

| Клавиша | Действие |
| --- | --- |
| Enter | Отправить учётные данные |
| Esc | Очистить ввод или отменить диалог PAM |
| F1 | Меню внешнего вида, если включено |
| F9 / F10 | Гибернация / сон, если доступны |
| F11 / F12 | Перезагрузка / выключение |

Действия питания требуют двух нажатий. Другая клавиша отменяет подтверждение. Экран остаётся заблокированным при отказе или отмене.

Добавьте rsdm lock в сочетание клавиш [niri](compositors/niri.md), [Hyprland](compositors/hyprland.md) или [Sway](compositors/sway.md).

## Несколько дисплеев и масштабирование {#multiple-displays-and-scaling}

```toml
[lock]
primary_output = "DP-1"
secondary_output = "black"
size = 2
```

При отсутствии `primary_output` выбирается подключённый выход с наибольшей площадью в пикселях. Форма разблокировки, меню, часы и статус появляются только на основном выходе. Дополнительные выходы показывают фон или непрозрачный чёрный экран. Настройка `off` сейчас ведёт себя как `black` и оставляет дисплеи включёнными.

Опустите `size` (или установите 1), чтобы использовать физические размеры символов консольного шрифта Greeter. Значения 2–12 увеличивают шрифт. Дробное масштабирование рабочего стола обрабатывается отдельно.

::: details Соответствие шрифту Greeter
DM публикует консольный шрифт в `/run/rsdm/console-font-<tty>.bin`. Lock читает его и использует 8×16 при недоступности. Перезапустите DM при следующем безопасном входе после смены консольного шрифта.
:::

## Внешний вид и личные настройки {#appearance-and-personal-settings}

```toml
[lock.design]
theme = "catppuccin"
wallpaper = "/etc/rsdm-wallpaper.png"
wallpaper_dim = 6
background = "rain"
background_opacity = 8
```

Используйте абсолютный путь к PNG или JPEG, читаемому пользователем рабочего стола. Обои масштабируются с заполнением и обрезаются по центру. Сначала применяется затемнение, затем анимация и карточка входа. Меню F1 показывает предварительный просмотр поддерживаемых визуальных настроек. Выберите **Save settings**, чтобы сохранить персональные переопределения в каталоге конфигурации пользователя. Дождитесь подтверждения сохранения перед разблокировкой. При следующем запуске они переопределят соответствующие системные настройки внешнего вида; точные поля и сброс описаны в [конфигурации](configuration.md#personal-lock-settings).

::: details Отрисовка и поведение фона
Эффекты, заполняющие всю область (plasma, fire), остаются видимыми за карточкой и текстом. Разреженные эффекты (matrix, rain, starfield) сохраняют фон темы под карточкой. При наличии обоев без анимации карточка прозрачная. Lock кеширует масштабированные обои для каждого выхода и повторно использует до двух буферов разделяемой памяти на выход. Без поддержки fractional-scale и viewporter применяется резервное целочисленное масштабирование.
:::

::: details Предварительный просмотр без блокировки
Из рабочей копии исходного кода с [зависимостями для сборки](development.md):

```sh
cargo run --locked -p rsdm-lock --example preview -- \
  /tmp/rsdm-lock-preview.png nord rsdm modern rain 15 none 8
xdg-open /tmp/rsdm-lock-preview.png
```

Позиционные аргументы: выходной файл, тема, предустановленный логотип, рамка, фон, номер кадра, необязательные обои (или none) и прозрачность фона. Пример использует демонстрационные учётные данные и не блокирует рабочий стол.
:::

## Аварийная разблокировка {#emergency-unlock}

Если блокировщик продолжает работать, но аутентификация недоступна, переключитесь на другой VT, войдите от имени администратора и выполните:

```sh
sudo rsdm unlock
# Для нескольких пользователей:
# sudo rsdm unlock --user alice
```

Можно также выполнить `rsdm unlock` напрямую: команда запросит авторизацию через sudo или pkexec при отсутствии sudo. При сбое блокировщика может потребоваться завершение затронутого сеанса композитора. Не полагайтесь на завершение процесса блокировщика как способ разблокировки. См. [безопасность](SECURITY.md#lock-screen) и [устранение неполадок](troubleshooting.md).
