# Совместимость {#compatibility}

RSDM предназначен для сеансов Wayland в Linux. Greeter работает в виртуальном терминале Linux и запускает установленные сеансы Wayland. Lock и Idle зависят от протоколов и политики композитора; Session Manager обладает отдельными возможностями управления жизненным циклом сеанса и завершением приложений.

## Требования {#requirements}

| Компонент | Требуется |
| --- | --- |
| DM / Greeter | Виртуальный терминал Linux, PAM, поддержка logind/seat, команда сеанса Wayland |
| Lock | [ext-session-lock-v1](https://wayland.app/protocols/ext-session-lock-v1), разрешённый композитором |
| Idle | [ext-idle-notify-v1](https://wayland.app/protocols/ext-idle-notify-v1); версия 2 для игнорирования ингибиторов |
| Session Manager | Linux pidfd, systemd 250+, logind, пользовательская шина D-Bus; один координатор графического сеанса на UID |
| Сборка | Rust 1.89+, PAM, Wayland, libxkbcommon, pkg-config; libSM/libICE для поддержки XSMP по умолчанию |

Выполните `wayland-info` на рабочем столе для просмотра опубликованных глобальных объектов Wayland и `rsdm session status` для просмотра доступных возможностей RSDM.

::: info X11
RSDM не запускает и не блокирует сеансы рабочего стола X11. Некоторые приложения XWayland внутри управляемого сеанса Wayland могут участвовать в XSMP или поддерживаемых механизмах закрытия окон. Это совместимость приложений, отдельная от поддержки менеджером входа X11.
:::

## Дистрибутивы {#distributions}

| Дистрибутив | Интеграция | Объём проверок |
| --- | --- | --- |
| [NixOS](installation/nixos.md) | Flake-модуль, стабильные и нестабильные пакеты | Система разработчика, модуль и изолированные тестовые ВМ NixOS |
| [Arch](installation/arch.md) | AUR `rsdm` и `rsdm-bin` | Доступны пакеты; приветствуются результаты тестирования рабочего стола |
| [Fedora](installation/fedora.md) | Файлы PAM для Fedora, ручная установка | Инструкции по сборке; приветствуются результаты тестирования рабочего стола |
| [Ubuntu](installation/ubuntu.md) | Файлы PAM в стиле Debian, ручная установка | Сборки CI на Ubuntu 26.04; приветствуются результаты тестирования рабочего стола |

Архивы релизов и пакеты flake доступны для `x86_64-linux` и `aarch64-linux`. Готовые бинарные файлы предназначены для Linux GNU; для старых дистрибутивов может потребоваться локальная сборка.

## Композиторы и окружения рабочего стола {#compositors-and-desktops}

| Сеанс | Жизненный цикл | Обработка окон зарегистрированных приложений |
| --- | --- | --- |
| [niri](compositors/niri.md) | Нативный `niri-session` или управляемый bare niri | Проверенный JSON IPC для управляемого композитора |
| [Sway](compositors/sway.md) | Управляемый bare WM | Проверенное нативное закрытие окон Wayland |
| [Hyprland](compositors/hyprland.md) | Управляемый bare WM или внешний поставщик | Проверенный Lua IPC на поддерживаемых версиях |
| GNOME | Нативный SessionManager | Нативные диалоги при подтверждённом владении |
| Plasma | Нативный LogoutPrompt | Нативные диалоги при подтверждённом владении |
| Standalone KWin | Управляемый композитор | Plasma window management при проверенном KWin 6.4+ и наличии разрешения |
| Wayfire | Управляемый композитор | Обнаружение через IPC только для чтения; резервная политика приложений |
| Labwc / River / другой управляемый WM | Управление при подтверждении готовности и владения | Обнаружение через реестр; резервная политика приложений |
| Существующий внешний сеанс | Частичная координация | Нативное делегирование при подтверждении; иначе общая подготовка приложений |

Таблица описывает реализованные механизмы Session Manager. Это не означает, что все композиторы поддерживают Lock или Idle. Нативные GNOME и Plasma могут требовать собственный блокировщик. Проверьте глобальные объекты протоколов и фактическую блокировку, прежде чем полагаться на RSDM Lock.

::: details Что покрывают изолированные проверки
Flake содержит тесты ВМ для нативных и bare-сеансов, внешнего подключения, времени жизни scope, Sway, niri, Hyprland, standalone KWin, обнаружения Wayfire, реестра Labwc/River, окон браузеров, Flatpak, мультимедийных приложений, питания, Lock и DM. Тестовые сценарии закрытия окон проверяют владение процессами, сохранение, отмену и сохранение посторонних экземпляров. Сценарий Hyprland использует 0.55.4; KWin требует проверенной версии 6.x не ниже 6.4.

Это изолированные тестовые сценарии, а не аппаратные проверки или полная матрица приложений. См. [разработку](development.md#validation) для актуальных имён проверок и [бэкенды сеанса](reference/session-backends.md) для ограничений.
:::

## Сообщить о конфигурации {#report-a-setup}

При отчёте о новой конфигурации укажите дистрибутив, версию RSDM, композитор и его версию, настройки PAM/связки ключей и соответствующие команды/статус. Не включайте пароли или другие секретные значения. Используйте [форму отчёта о тестировании](https://github.com/Frysuni/rsdm/issues/new/choose).
