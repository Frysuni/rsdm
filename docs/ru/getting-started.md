# Начало работы {#getting-started}

RSDM объединяет четыре компонента. Выберите только необходимые.

| Компонент | Назначение | Настройка TOML по умолчанию |
| --- | --- | --- |
| DM / Greeter | Вход через PAM на виртуальном терминале Linux и запуск сеанса Wayland | `dm.enable = true` |
| Lock | Блокировка экрана внутри сеанса Wayland с аутентификацией | `lock.enable = false` |
| Idle | Автоматическая блокировка при бездействии | `idle.enable = false` |
| Session Manager | Запуск приложений, публикация окружения и корректное завершение сеанса | `session_manager.enabled = true` |

DM — исполняемая часть менеджера входа. Greeter — его интерактивный терминальный интерфейс. Lock — отдельный клиент Wayland с собственной конфигурацией.

## Выберите дистрибутив {#choose-your-distribution}

- [NixOS](installation/nixos.md) — декларативный модуль и пакеты.
- [Arch Linux](installation/arch.md) — пакеты AUR с исходным кодом или готовым бинарным файлом.
- [Fedora](installation/fedora.md) — локальная сборка или архив релиза.
- [Ubuntu](installation/ubuntu.md) — локальная сборка или архив релиза.

Все руководства устанавливают необходимые файлы для работы. Требования различаются между компонентами; проверьте [совместимость](compatibility.md).

## Первый вход {#first-login}

1. Установите композитор Wayland и убедитесь, что он запускается при вашем обычном входе в систему.
2. Установите RSDM, проверьте настройки PAM и выберите виртуальный терминал Greeter.
3. Проверьте конфигурацию командой `rsdm validate-config`.
4. Активируйте DM согласно руководству дистрибутива. Войдите и выберите сеанс (или задайте `dm.fixed_session`, чтобы пропустить выбор).
5. На рабочем столе выполните `rsdm session status` и проверьте доступные возможности.

::: warning Перед сменой менеджера входа
Сохраните доступ к другому виртуальному терминалу и обычному консольному входу. Сохраните работу, выйдите из текущего графического сеанса и переключитесь в эту консоль перед заменой службы менеджера входа.
:::

## Первая блокировка {#first-lock}

Включите Lock в конфигурации и выполните следующие действия **от имени своего пользователя внутри Wayland**:

::: code-group

```toml [TOML]
[lock]
enable = true
```

```nix [NixOS]
services.rsdm.lock.enable = true;
```

:::

```sh
rsdm lock
```

Разблокируйте экран учётными данными текущей учётной записи. Настройте сочетание клавиш композитора по [руководству Lock](lock.md), затем при необходимости включите [Idle](idle.md).

## Корректное завершение сеанса {#use-orderly-shutdown}

Session Manager включён по умолчанию для входов, запущенных через RSDM. Зарегистрируйте приложение, чтобы назначить ему политику завершения:

```sh
rsdm app -- foot
rsdm session status
```

Используйте `rsdm session stop` для выхода. Команда подготавливает зарегистрированные приложения перед завершением управляемого сеанса. См. [Session Manager](session-manager.md) для внешних сеансов, нативных рабочих столов и поведения при тайм-аутах.
