# Связки ключей {#keyrings}

RSDM использует стек PAM входа для разблокировки связок ключей. Собственный PAM-модуль связки получает учётные данные входа, запускает агент и публикует его окружение. DM передаёт это окружение рабочему столу.

## NixOS {#nixos}

```nix
services.rsdm.keyring = "auto";
```

| Значение | Поведение |
| --- | --- |
| auto | Сначала обнаруживать GNOME Keyring, затем KWallet |
| gnome | Выбрать GNOME Keyring |
| kwallet | Выбрать KWallet |
| none | Оставить интеграцию PAM связки ключей вашей конфигурации |

Режим auto проверяет существующие настройки PAM (и службу GNOME Keyring). Выберите явно, если установлены обе связки. Для пользовательского PAM-модуля выберите none и добавьте соответствующие структурированные правила PAM auth/session в security.pam.services.rsdm.

## Другие дистрибутивы {#other-distributions}

| Дистрибутив | Поставляемый стек PAM |
| --- | --- |
| Arch | system-login и необязательные модули GNOME Keyring и KWallet |
| Fedora | login (наследует политику дистрибутива) |
| Ubuntu / Debian | common-auth, common-account, common-password и common-session |

Установите нужный пакет связки ключей и проверьте /etc/pam.d/rsdm. Следуйте обычным правилам интеграции связки с PAM для своего дистрибутива, включая имя модуля и порядок правил auth и session. В файлах в стиле Debian могут потребоваться явные необязательные хуки связок ключей.

::: warning
Изменения PAM влияют на вход. Держите другой аутентифицированный VT открытым во время проверки. Не копируйте весь стек из другого дистрибутива.
:::

::: details Что происходит при входе
Хук PAM auth получает учётные данные; хук session открывает связку ключей и запускает её агент. pam_systemd регистрирует вход рабочего стола. RSDM использует полученное окружение PAM, включая переменные агента вроде SSH_AUTH_SOCK, если они предоставлены. Завершением работы связки управляют PAM-модуль и политика времени жизни рабочего стола. Lock использует отдельный стек PAM только для аутентификации и не открывает новый сеанс входа.
:::

## Устранение неполадок {#troubleshoot}

Проверьте, что PAM-модуль установлен и включён в стек входа. Пароль связки должен совпадать с учётными данными входа для автоматической разблокировки. Проверьте журнал на ошибки PAM и наличие ожидаемых переменных агента внутри рабочего стола. Не публикуйте их значения, если они содержат конфиденциальную информацию.

См. [ArchWiki GNOME Keyring](https://wiki.archlinux.org/title/GNOME/Keyring), [KDE Wallet](https://wiki.archlinux.org/title/KDE_Wallet) и [безопасность](SECURITY.md).
