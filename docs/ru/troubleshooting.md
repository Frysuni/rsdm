# Устранение неполадок {#troubleshooting}

Перед изменениями DM или PAM сохраняйте доступ к другому рабочему VT. Выполняйте команды рабочего стола от вошедшего пользователя.

## Сбор диагностики {#collect-diagnostics}

```sh
rsdm --version
rsdm validate-config
rsdm status
rsdm session status
rsdm logs --lines 100
```

::: details Журналы и службы systemd
```sh
systemctl status rsdm.service
journalctl -b -u rsdm.service
systemctl --user status graphical-session.target
systemctl --user status rsdm-idle.service
journalctl --user -b
```

Для экземпляра шаблона замените `rsdm.service` на `rsdm@tty2.service` или фактический unit. Фильтр DM в CLI охватывает стандартный unit. Используйте `logging.level` = "debug" или `RUST_LOG`=rsdm=debug для подробностей при следующем безопасном запуске.
:::

## Вход и Greeter {#login-and-greeter}

| Симптом | Что проверить |
| --- | --- |
| Нет Greeter при загрузке | Включённый unit, `graphical.target`, TTYPath и псевдоним display-manager |
| VT уже занят / ожидание | Активный вход удерживает VT; подождите или используйте другую консоль |
| Нет списка сеансов | Установленные desktop-файлы Wayland и `dm.session_dirs`; проверьте fixed_session |
| Ошибка аутентификации | Стек PAM, политика учётной записи/групп и ограничение попыток |
| Искажённый TTY | Используйте поставляемый unit с выводом в журнал; проверьте консоль ядра и шрифт |
| Связка ключей остаётся заблокированной | [Настройка PAM для связок ключей](keyrings.md) |
| Greeter дублируется на дисплеях | Linux fbcon предоставляет одну общую сетку VT |

Если вход не работает, используйте другой VT для просмотра конфигурации и журналов. См. [активацию и восстановление](installation/activate.md) или откатите конфигурацию NixOS. Не перезапускайте службы, удерживающие активный сеанс, только для сбора журналов.

## Lock и Idle {#lock-and-idle}

| Симптом | Что проверить |
| --- | --- |
| Lock не запускается | `lock.enable`, протокол session-lock Wayland, текущего пользователя, персональное переопределение |
| Неверный монитор | `lock.primary_output`; используйте список выходов композитора |
| Шрифт отличается от Greeter | Удалите переопределение size и повторно опубликуйте консольный шрифт при следующем запуске DM |
| Обои не видны | Абсолютный читаемый путь PNG/JPEG и wallpaper_dim выше нуля |
| Размытие при дробном масштабе | Поддержку `fractional-scale-v1` и viewporter; проверьте scale_120 в отладочных журналах |
| Idle не блокирует | `idle.enable`, запущенную пользовательскую службу, глобальные объекты протокола и ингибиторы |
| Хук не сработал | Подтверждение встроенного блокировщика, код выхода пользовательского блокировщика и журналы хуков |

Используйте [аварийную разблокировку](lock.md#emergency-unlock) только из аутентифицированного сеанса администратора, если работающий блокировщик не может аутентифицировать. При сбое блокировщика может потребоваться завершение затронутого графического сеанса.

## Session Manager {#session-manager}

| Симптом | Что проверить |
| --- | --- |
| inactive / disabled | Запустите или подключитесь внутри правильного графического входа; проверьте политику enabled |
| starting сохраняется | Готовность композитора; выполните finalize внутри рабочего стола |
| partial | Прочитайте причины ограничений возможностей; внешние сеансы намеренно имеют ограниченное управление жизненным циклом |
| Приложения нет в статусе | Зарегистрируйте первый экземпляр через rsdm app; существующие процессы не перенимаются |
| Приложение принудительно завершено | Используйте его документированный метод выхода, увеличьте тайм-аут или примените cancel, где поддерживается |
| prepared | Нативное управление недоступно или жизненный цикл подключён; выйдите из исходного рабочего стола отдельно |
| delegated | Проверьте нативный диалог выхода; принятие запроса не означает окончательного завершения |
| Отмена отклонена | Подготовка могла уже перейти к необратимому демонтажу |

См. [статус и результаты](session-manager.md#status-and-outcomes) и [ограничения бэкендов](reference/session-backends.md).

## Сообщить о проблеме {#report-an-issue}

Укажите версию RSDM, дистрибутив, композитор и его версию, соответствующую конфигурацию (удалите чувствительные значения), статус сеанса и короткий отрывок журнала. Укажите шаги воспроизведения и ожидаемое поведение. Не включайте пароли, токены или приватные данные аутентификации.

[Открыть issue](https://github.com/Frysuni/rsdm/issues/new/choose).
